# CCC Pipeline Tools

## What it does
helps me identify overdue followups, count contacts and helps me plan followup dates around holidays. followups are due after seven days

## How to run it
Open a codespace and run python3 follow_up_finder.py using the fictional sample file. python 3 is required and command goes in the terminal.

## What it does not do
doesn’t send messages, contact people, connect to LinkedIn or modify CRM records


## Privacy
uses fictional contact information, the .gitignore keeps the private folder out of git
